# Рабочий профиль — для агента по доходу (черновик, на одобрение владельца)

## Человек
- Серёга, ник на GitHub — Sereban-glitch.
- Где: Украина, Запорожье. Точный адрес не передаётся и не нужен.

## Навыки
- Go, Python, Telegram-боты, мини-приложения (Next.js), видеоконвейер (Shorts: нарезка, озвучка, субтитры), PostgreSQL, самостоятельный хостинг.

## Активы
- Публичные репозитории на GitHub: видеопайплайн, строительный бот Proakt, бот информационных запросов, мини-приложения.
- Сайт-портфолио, ноутбук на Linux, облачная машина (маленькая, 1 ГБ RAM — тяжёлый рендер только на ноутбуке).

## Пилот
- Строительный бот уже тестируется одним строителем по дружбе, бесплатно. Его не трогать, платных клиентов искать отдельно.

## Цель
- Первый реальный доход — хотя бы 1 гривна, как тест канала денег. Дальше — рост.

## Деньги
- Только гривна. На поиск и подготовку — ноль трат. Платное продвижение и платные подписки — только по отдельному слову владельца.

## Связь с клиентами
- Переписка (Telegram, чат), не звонки.

## Решения
- Всё публикует, отправляет и оплачивает только владелец. Агент готовит черновики и план, сам ничего не публикует, никому не пишет, денег не тратит.

## Запрещено агенту
- Секреты, пароли, токены, личные данные, выдуманные факты. Догадки — отдельно, в разделе «не проверено».
